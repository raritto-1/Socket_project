# Python Chatting App (Socket Programming)

This is a simple **Chatting Application** built using Python's built-in `socket` library. The project demonstrates basic network programming by creating a server-client chat system that allows multiple users to communicate over a network.

---

## Features

- Real-time messaging using TCP sockets
- Separate server and client-side code
- Multiple clients can connect to the server (basic implementation)
- Simple and lightweight console-based chat interface
